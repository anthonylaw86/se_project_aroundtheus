# Around The U.S. (project 3)

Around The U.S. features a place where users can like & share photographs. It is a JavaScript project that uses modals to edit user information as well as add/remove photographs. The site has also been designed to be viewable on popular screen sizes such as phones or tablets.

## Project Features

- HTML
- CSS
- JavaScript
- JavaScript API's
- Adaptive Design
- Interactive Forms & Images
